# claimpins

**claimpins are self-verifying evidence objects** — content-addressed bundles that
carry a scientific or computational claim together with its evidence and a
machine-runnable verification contract, so any third party (human or AI agent) can
check the claim offline with one command.

The **claimpins standard** (specification, reference verifier, discipline profiles)
will be published here. Status: specification in draft; watch this organization.

Canonical namespaces: claimpins.org / claimpins.ai.
Alias organization: github.com/claimpin (singular) redirects here by signpost.
